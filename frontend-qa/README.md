# ReqLint Frontend + QA Workspace

Welcome, **Frontend & QA Engineer**! This folder contains the Next.js 14 Web UI and Cypress E2E Quality Assurance test suite.

## Responsibilities
1. **Frontend**: Building interactive Monaco SRS Editor, real-time score visualizer, and IEEE 29148 / INVEST suggestion cards.
2. **QA**: Writing Cypress / Playwright E2E integration tests to verify SRS audit flows and API contracts.

## Quickstart

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```
   Access application at `http://localhost:3000`

3. **Run E2E QA Tests**:
   ```bash
   npm run test:e2e
   ```
