# 1. Manajemen Embargo (Embargo Management)
Sebagai collection curator, saya ingin mencabut embargo untuk suatu objek dengan cara yang sederhana.
Sebagai collection curator, saya ingin item-item dijadikan tersedia di bawah izin yang dikonfigurasikan setelah tanggal embargo tercapai.

Sebagai DigitalRecords Archivist, saya ingin alat penyerapan massal mengenali dan menetapkan embargo, izin untuk item yang diembargo harus memungkinkan semua orang melihat metadata, serta kurator koleksi dan administrator repositori mengunduh berkas.
Sebagai DigitalRecords Archivist, saya ingin repositori mencabut embargo pada tanggal rilis dan mengatur kontrol akses ke konfigurasi yang ditetapkan pada item pada tanggal tersebut.
Sebagai visitor, saya ingin melihat status embargo dan tanggal rilis ditampilkan dengan jelas dan mungkin disorot dengan cara tertentu.

Sebagai DigitalRecords Archivist, saya ingin melihat dan mengunduh ringkasan metadata embargo untuk semua ETD di dalam repositori.
