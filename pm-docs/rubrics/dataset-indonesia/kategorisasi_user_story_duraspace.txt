# 1. Manajemen Struktur & Hierarki Koleksi
Sebagai repository manager, saya ingin mengetahui semua koleksi dan objek dalam DAMS yang menjadi tanggung jawab kustodian saya.
Sebagai repository manager, saya ingin mengetahui semua koleksi yang menjadi tanggung jawab kuratorial saya.
Sebagai user, saya ingin membuat daftar semua koleksi dan objek dalam DAMS yang dimiliki oleh suatu unit perpustakaan.
Sebagai the DAMS manager, saya ingin dapat membuat daftar untuk penelusuran semua koleksi formal yang terwakili dalam DAMS bersama dengan hubungan yang sesuai.
Sebagai repository manager, saya ingin menyusun koleksi, membatasi koleksi pada item-item yang berbagi asal-usul yang sama, membatasi koleksi untuk mewakili bagian dari koleksi yang memiliki satu asal-usul, atau mengumpulkan koleksi dari koleksi dan objek lain.
Sebagai repository manager, saya ingin menyatakan bahwa satu koleksi terkait dengan koleksi lain.

# 2. Deskripsi Metadata Koleksi & Tautan Eksternal
Sebagai repository manager, saya ingin mendeskripsikan koleksi, termasuk judulnya, tanggal inklusif / massalnya, bahasa(-bahasa)nya, dan banyak aspek lainnya.
Sebagai repository manager, saya ingin menunjukkan nama-nama yang terkait dengan koleksi baik sebagai pencipta, sumber, atau subjek.
Sebagai repository manager, saya ingin menunjukkan subjek yang terkait dengan koleksi.
Sebagai repository manager, saya ingin menunjukkan deskripsi lain dari koleksi yang berada di luar DAMS dan kemungkinan penting bagi pengguna.

# 3. Struktur Komponen & Objek Kompleks

Sebagai repository manager, saya ingin menautkan, jika sesuai, suatu komponen ke komponen lain atau ke suatu berkas.
Sebagai repository manager, saya ingin mengaitkan berkas konten dengan objek atau komponen objek.
Sebagai DAMS manager, saya ingin menampilkan dalam urutan yang ditetapkan semua komponen yang menyusun suatu objek.
Sebagai user, saya ingin dapat melihat dan menavigasi hierarki komponen dari suatu objek.

# 4. Deskripsi Metadata Tingkat Objek & Komponen

Sebagai repository manager, saya ingin mendeskripsikan setiap komponen seperlunya, termasuk judul, tanggal, bahasa, dan aspek lainnya.
Sebagai repository manager, saya ingin menunjukkan untuk suatu objek atau komponen objek tempat publikasi, penerbit, edisi, dll., jika relevan.
Sebagai user, saya ingin mengetahui untuk suatu objek atau bagian komponennya tempat publikasi, penerbit, dll.
Sebagai repository manager, saya ingin mendeskripsikan berbagai faset dari koleksi, objek, atau komponen objek yang tidak dapat dialamatkan melalui entitas judul, tanggal, nama, dan subjek.
Sebagai user, saya ingin mengetahui tentang berbagai aspek dari suatu koleksi, objek, atau komponen objek, seperti cakupan dan konten, berbagai pengenal, ketentuan yang mengatur penggunaan/akses, dll.
Sebagai repository manager, saya ingin menunjukkan versi atau deskripsi eksternal apa pun dari suatu objek yang mungkin penting bagi pengguna.
Sebagai user, saya ingin tahu tentang versi lain dari objek atau metadatanya yang mungkin berguna bagi saya.
Sebagai repository manager, saya ingin menunjukkan semua versi atau deskripsi relevan lainnya dari suatu sumber daya yang berada di luar DAMS.
Sebagai user, saya ingin mengetahui semua versi atau deskripsi relevan lainnya dari sumber daya tersebut.

Sebagai repository manager, saya ingin mengetahui semua berkas konten dalam DAMS untuk objek repositori saya.

Sebagai DAMS manager, saya ingin mengetahui, melalui manajer pelestarian, objek apa pun yang integritas atau keasliannya dipertanyakan atau yang telah diperbarui ke format berkas yang lebih mutakhir.
